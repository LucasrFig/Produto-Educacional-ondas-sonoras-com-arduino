### Como utilizar o código?
  1.  Instale:
      - O VS Code;
      - O Git (para baixar do GitHub);
      - Os Drivers USB da sua placa Arduino para que o PC a reconheça.
  2.  No VS Code, abra a aba "Extensões" e instale a extensão PlatformIO IDE (ela deve puxar a extensão C/C++ da Microsoft automaticamente);
  3.  Aperte (_Ctrl+Shift+P_) no VS Code e use o comando **Git: Clone** para colar a URL do repositório para baixá-lo;
      **URL:**(https://github.com/LucasrFig/Produto-Educacional-ondas-sonoras-com-arduino.git);
  4.  Vá em Arquivo > Abrir Pasta... (File > Open Folder...) no menu do VS Code;
  5.  Navegue até a pasta que você baixou e selecione a subpasta Ondas. **_(Ex: C:\MeusProjetos\Produto-Educacional-ondas-sonoras-com-arduino\Ondas)_**;
  6.  Aguarde o PlatformIO baixar e configurar todas as ferramentas e bibliotecas do projeto (baseado no arquivo platformio.ini);
  7.  Conecte seu Arduino na porta USB;
  8.  Na barra na parte inferior do VS Code, procure pelo ícone de "Upload" do PlatformIO (geralmente uma seta para a direita →) e clique nele para carregar o código em seu arduino;
  9.  Pronto!!
